# Заметки по проекту

1. Если ничего не поможет, то будем использовать векторизацию.
2. В альтернативном режиме просмотра привязать прокрутку к Ctrl + колесику мыши.
3. Для некоторых инструментов предусмотреть runtime-предпросмотр результата: при достаточно малой размерности его можно держать включённым постоянно, а при большой размерности показывать предупреждение в модальном окне при включении. Порог размерности и список инструментов пока не определены.
4. Добавить инструмент обрезки прозрачных краёв изображения: находить крайние пиксели с ненулевым значением альфа-канала и подгонять рамку изображения ровно под нарисованное содержимое. Полупрозрачные пиксели тоже учитывать.
5. Исправить белый квадрат в углу пересечения горизонтальной и вертикальной полос прокрутки, когда обе полосы видны одновременно. Угол должен соответствовать тёмному оформлению интерфейса.
6. В сравнении двух вариантов показывать их в одинаковом визуальном масштабе: вариант с меньшими размерами увеличивать до отображаемого масштаба большего, чтобы содержимое было сопоставимо рядом. Сохранять пропорции изображения.
