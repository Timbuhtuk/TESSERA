# Tessera visual assets

- Brand contains the Windows application icon, its PNG version for the interface, and the SVG mark for the repository README. After replacing `Brand/app.ico`, run `Brand/Build-Icon.ps1` on Windows to regenerate the interface PNG.
- Icons contains the settings gear and the Unreal Engine mark from the UE 5.3 editor. `Icons/Results` uses processing operation IDs as SVG filenames. `Icons/Workspace` contains the icons for library asset types.
- Previews contains the sample photo used by the palette tooltips.
- Fonts contains the license texts shipped with the app.
