# Гипотеза 1: градиент как признак дефекта формы

Проверка выполнена на пяти FIMOZ после одинакового базового конвейера `finish-pixel-art` (157×157). Скрипт `RunGradientHypothesis.ps1` применяет существующий `clean-dark-contours` с настройками по умолчанию и с обязательной противоположностью общему градиенту (`--require-common-gradient`). Размер всех выходов — 157×157, альфа не изменилась. PNG и полный JSON счётчиков лежат в локальном игнорируемом Git каталоге `artifacts/shape-gradient/`.

Это проверка только двух заранее выбранных режимов; малое число изменений не доказывает, что каждый пиксель исправлен верно. Обязательный общий градиент почти полностью выключил очистку на этой выборке. Пока нет основания считать градиент достаточным самостоятельным механизмом решения всех названных пользователем проблем формы. Окончательный визуальный pass/fail отдаётся независимому валидатору.
