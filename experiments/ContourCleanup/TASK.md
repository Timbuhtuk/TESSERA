# Задача: очистить шум на чёрных контурах перчатки

Ветка `codex/contour-black-lines` изолирует эксперименты от текущего результата в основном checkout. Исходник: `fixtures/T_StrongHand_UNP.png`, SHA-256 `59440B9D5797DCFD06375B9FA1910FA9295388AA1E1365B005F4202D8A1275D0`.

Критерий приёмки — визуально более чистые чёрные линии на исходной перчатке без разрушения пальцев, теней, окантовки манжеты и силуэта. Проверять результат при масштабе 1:1 и с ближайшим увеличением; отдельно сравнивать область пальцев, ладони, большого пальца и манжеты. Счётчик изменённых пикселей не служит оценкой качества.

Фиксировать для каждого варианта параметры, число замен, карту изменённых пикселей и PNG результата. Проверять сохранение размеров и альфы побайтно.

Статус: локальная проверка на перчатке завершена. В CLI по умолчанию действует сравнение окружения 3×3 с учётом цветов, основной и расширенный взвешенный поиск цветовых повторов, симметричный поиск и поиск редкого повторяющегося тёмного цвета на первом проходе, а также узкие проверки по снижению локального перепада и градиенту. Для редкого тёмного цвета включены проверки диагонального мостика по градиенту похожих цветов, редкости близких оттенков в палитре PNG, локального перепада при низком согласии светлых соседей и выступа при трёх тёмных соседях. Расширенная проверка палитры при низком цветовом согласии имеет собственные настраиваемые пороги. Дополнительно включены ограниченная проверка контрастного выброса и мягкое согласие соседей только при приросте LAB L не менее 60. На исходных 50, другой расстановке шума, геометрически изменённых 50 и 50 разных объектах режим исправил соответственно 351/400, 348/400, 326/400 и 338/400 вставок. Чистые PNG изменились на 0, 0, 29 и 35 пикселей. На 50 разных объектах только одно исправление точно совпало по цвету с чистым оригиналом. На исходной перчатке режим даёт 58 замен за два прохода без изменения размера и альфы. Все пороги и выключатели доступны в CLI; причины отказа можно сохранить через `--candidate-audit`. Общий пропуск цветового порога по снижению перепада остаётся экспериментальным и выключен по умолчанию. На 38 из 50 разных объектов внесённый шум сохранился; общая приёмка остаётся открытой. Подробности и исторические замеры записаны в `RESULTS.md`.
