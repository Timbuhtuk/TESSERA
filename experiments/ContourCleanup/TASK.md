# Задача: очистить шум на чёрных контурах перчатки

Ветка `codex/contour-black-lines` изолирует эксперименты от текущего результата в основном checkout. Исходник: `fixtures/T_StrongHand_UNP.png`, SHA-256 `59440B9D5797DCFD06375B9FA1910FA9295388AA1E1365B005F4202D8A1275D0`.

Критерий приёмки — визуально более чистые чёрные линии на исходной перчатке без разрушения пальцев, теней, окантовки манжеты и силуэта. Проверять результат при масштабе 1:1 и с ближайшим увеличением; отдельно сравнивать область пальцев, ладони, большого пальца и манжеты. Счётчик изменённых пикселей не служит оценкой качества.

Фиксировать для каждого варианта параметры, число замен, карту изменённых пикселей и PNG результата. Проверять сохранение размеров и альфы побайтно.

Статус: локальная проверка на перчатке завершена. В CLI по умолчанию действует сравнение окружения 3×3 с учётом цветов, основной и расширенный взвешенный поиск цветовых повторов, симметричный поиск и поиск редкого повторяющегося тёмного цвета на первом проходе, а также узкие проверки по снижению локального перепада и градиенту. Для редкого тёмного цвета включены проверки диагонального мостика по градиенту похожих цветов, редкости близких оттенков в палитре PNG, локального перепада при низком согласии светлых соседей и выступа при трёх тёмных соседях. Исключительно редкий оттенок может пройти финальную проверку без снижения локального перепада, если остальные фильтры уже пройдены. Добавлено сравнение фрагментов 3×3 без центра с более строгим допуском для раннего отказа по цвету и групповая проверка разбросанных повторов тёмного оттенка с более строгим сравнением образцов при большом числе близких оттенков и при недостатке ранее принятых исправлений точного оттенка; для подтверждённых групп с плотной палитрой средний порог светлых соседей ниже. Дополнительно включены защита от осветления исходного материала по похожему фрагменту 3×3, ограниченная проверка контрастного выброса и мягкое согласие соседей только при приросте LAB L не менее 60. На исходных 50, другой расстановке шума, геометрически изменённых 50 и 50 разных объектах режим исправил соответственно 358/400, 353/400, 334/400 и 388/400 вставок. Дополнительная проверка подтверждённой группы по светлому и тёмному образцу включена с отношением ошибок 0,4; выбор цвета образца или интерполяции и защита соседей после групповой замены настраиваются через `--confirmed-group-*`. Чистые PNG изменились на 0, 0, 29 и 7 пикселей. Отказы защиты исходного материала сохраняются между проходами, если точка не была исправлена; правило можно выключить через `--no-exemplar-material-interpass`. На 50 разных объектах только одно исправление точно совпало по цвету с чистым оригиналом. На исходной перчатке режим даёт 58 замен за два прохода без изменения размера и альфы. Все пороги и выключатели доступны в CLI; причины отказа можно сохранить через `--candidate-audit`. Общий пропуск цветового порога по снижению перепада остаётся экспериментальным и выключен по умолчанию. На 8 из 50 разных объектов сохранилось 12 внесённых точек; общая приёмка остаётся открытой. Подробности и исторические замеры записаны в `RESULTS.md`.

Для изображений с известной сеткой размером от 2 пикселей появился отдельный режим `clean-dark-contours --grid-cell-size N`. Он убирает только одиночные выбросы по согласованной тройке соседей из одной ячейки 2×2; цветовой допуск задаётся `--grid-color-tolerance`. При отсутствии размера сетки сохраняется прежний контурный алгоритм. Проверка 50 изображений, увеличенных в 2 раза, восстановила точно все 400 внесённых одиночных точек и не изменила ни один из 50 чистых PNG. Этот опыт не закрывает приёмку изображений с исходной сеткой 1×.
