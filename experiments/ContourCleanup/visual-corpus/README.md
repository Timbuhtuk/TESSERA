# 50 отдельных пиксель-арт объектов

Две исходные таблицы по 25 объектов созданы imagegen. Таблицы включают разные предметы и персонажей; в `clean/` находятся отдельные PNG 96×96, полученные из ячеек методом nearest neighbor. Фон непрозрачный светлый. `noisy/` содержит те же изображения с восемью вставленными тёмными точками в каждом. Координаты и имена указаны в `manifest.json`.

Это искусственный набор для проверки алгоритма, а не коллекция эталонных работ художников. Генерация самих исходных таблиц вероятностная; сохранённые `source-01.png` и `source-02.png` позволяют повторить вырезание и внесение шума. Скрипт `../PrepareVisualCorpus.py` требует Python, Pillow и NumPy:

```powershell
python experiments/ContourCleanup/PrepareVisualCorpus.py experiments/ContourCleanup/visual-corpus
./experiments/ContourCleanup/RunCorpus.ps1 -CorpusRoot experiments/ContourCleanup/visual-corpus -Passes 2
dotnet experiments/ContourCleanup/bin/Release/net8.0-windows/ContourCleanup.dll evaluate-corpus experiments/ContourCleanup/visual-corpus
python experiments/ContourCleanup/ReviewVisualCorpus.py experiments/ContourCleanup/visual-corpus
```

В `RunCorpus.ps1` используется собранный Tessera CLI. Программа создаёт результаты и листы просмотра внутри этого каталога; они игнорируются Git. `ReviewVisualCorpus.py` собирает два обзорных листа по 25 объектов с чистой, загрязнённой и обработанной версией. Чистые исходники и загрязнённые версии сохраняются под контролем версий, чтобы сравнение было воспроизводимым.

Первый контрольный запуск CLI до проверки цветовых повторов исправил 327/400 внесённых точек, но изменил также 917 других пикселей в загрязнённых версиях и 936 пикселей на чистых версиях. Новый режим с цветовой проверкой по умолчанию исправляет 187/400 точек, изменяет ещё 34 пикселя в загрязнённых и 35 в чистых версиях. Ложных замен стало значительно меньше, но общая приёмка остаётся открытой; подробности в `../RESULTS.md`.

Промпт для первой исходной таблицы: сетка 5×5 из 25 разных предметов (голова дракона, космический корабль, велосипед, рыба, дом, кактус, книга, ключ, камера, торт, сова, карта, песочные часы, парусник, чайник, жук, гитара, волшебная шляпа, ракета, клубника, корона, снеговик, фонарь, грибной дом, лиса). Строгий пиксель-арт, ограниченная палитра, тонкий почти чёрный контур, светлый нейтральный фон, отдельная ячейка для каждого объекта, без текста и намеренных шумовых пикселей.

Промпт для второй таблицы: те же требования к сетке и стилю, объекты — пиратский череп, яблоко, шлем рыцаря, воздушный шар, кот, компас, бабочка, поезд, пакет молока, букет, черепаха, кристалл, боксёрская перчатка, скрипка, чашка, осьминог, башня, лейка, водолазный шлем, ель, монета, попугай, мороженое, часы, лицо робота.
