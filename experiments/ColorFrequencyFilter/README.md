# Эксперимент: фильтр редких цветов

Инструмент удаляет точные RGB-цвета, частота которых **строго ниже** заданной доли
видимых пикселей. Для каждого удаляемого цвета выбирается ближайший по CIE76 Lab
из цветов, прошедших порог. Частоты считаются один раз по исходнику; замены не
меняют состав сохранённой палитры. Новые RGB-цвета не создаются.

Полностью прозрачные пиксели исключены из статистики и сохраняются без изменений.
У видимых пикселей альфа сохраняется точно; доля считается по количеству пикселей,
а не с весом их прозрачности. Размер и положение пикселей не меняются.

Из корня репозитория:

```powershell
dotnet build experiments/ColorFrequencyFilter/ColorFrequencyFilter.csproj -c Release -m:1 -p:UseSharedCompilation=false
dotnet run --project experiments/ColorFrequencyFilter/ColorFrequencyFilter.csproj -c Release -- "C:\path\input.png" -o "artifacts\frequency-filter\result.png" --threshold-percent 0.01 --json
```

`--threshold-percent 0.01` означает, что цвет должен занимать хотя бы 0,01%
видимых пикселей. Если ни один цвет не проходит порог, команда завершается с
ошибкой и сообщает максимальную частоту. Исходник нельзя перезаписывать;
существующий результат заменяется только с `--overwrite`.

Это глобальный эксперимент без защиты мелких деталей: редкая звезда, контур или
блик могут исчезнуть, если их точный RGB не достиг порога.
